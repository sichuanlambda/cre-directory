About Homesage.ai

Homesage.ai is a residential real estate data and analytics platform sold mainly as an API, with investor-facing tools layered on top. The company says it covers more than 155 million US residential properties and analyzes MLS and off-market listings daily. Its API library offers more than 20 endpoints, including property information, investment potential, property condition, renovation cost, renovation return, flip return, long-term and short-term rental estimates, comps, a price flexibility score and a full property report. Condition assessments are produced with computer vision run on listing imagery. For non-developers there is an investment property search, full property reports, and DealFinder, a Chrome extension and mobile app that detects addresses on listing sites and pulls up a report. The company also offers a real estate MCP for connecting AI assistants to its data, and custom AI solutions for lenders, insurers and proptech firms. API plans are credit-based and published, starting at $150 a month, with a free sandbox that returns test data. Coverage is residential only, so it suits residential investors, lenders and developers rather than commercial asset teams.

Homesage.ai Features

✦ Property and Valuation Endpoints Property information, home value graph, comps and full property report endpoints.
✦ Investment and Renovation Endpoints Investment potential, renovation cost, renovation return and flip return calculations.
✦ Rental Estimates Separate long-term and short-term rental estimate endpoints.
✦ Sandbox and MCP Free sandbox with test data for development, plus an MCP for AI assistants.
✦ Property Condition Assessment Computer vision models grade property condition from listing images.
✦ Price Flexibility Score A score intended to indicate how negotiable a seller may be, marketed as a seller motivation signal.
✦ Full Property Reports AI-generated reports combining valuation, condition, renovation and return metrics.
✦ Investment Property Search Search and filter listings for flip and rental opportunities.
✦ DealFinder Extension and App Chrome extension and iOS/Android app that detect addresses on listing sites and open a report.
