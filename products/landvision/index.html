About Landvision

LandVision, now rebranded as LightBox Vision, is a nationwide property data mapping platform from LightBox (formerly Digital Map Products). The platform provides real estate professionals with access to parcel boundaries, building footprints, ownership data, zoning information, and more through an interactive map-based interface. LightBox Vision is built on proprietary datasets including the industry-leading LightBox ID for connecting datasets, a proprietary geocoder using ML/AI, and zoning data with enhanced report ordering. The platform supports use cases including investment property search, market analysis, site selection, and comprehensive ownership research.

Landvision Features

✦ Parcel Boundaries Nationwide parcel boundary maps with property details.
✦ Building Footprints Building footprint data for commercial and residential structures.
✦ Ownership Data Comprehensive property ownership information and history.
✦ LightBox ID Industry-leading unique identifier connecting datasets across the platform.
✦ Interactive Map Platform User-friendly mapping application for property research and analysis.
✦ Zoning Data Zoning codes, types, and enhanced zoning reports available in-platform.
✦ AI Geocoder Proprietary geocoder using ML/AI for precise address matching.
✦ Property Reports Detailed property reports with ownership, tax, and zoning data.
✦ Data Filtering Filter through property data by multiple criteria for targeted research.
✦ Data Export Export data for further analysis in external tools.
✦ Training Resources In-platform help resources, videos, and webinars.
