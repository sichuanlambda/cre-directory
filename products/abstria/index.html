About Abstria

Abstria is a lease abstraction tool for commercial real estate teams. Users upload leases, amendments, SNDAs, estoppels, LOIs and related documents as PDFs, and the software extracts more than 200 structured fields per lease, with each field hyperlinked to the page and clause it came from. Results open in a dual-panel editor beside the source PDF for review, and uploaded amendments are compared against the original lease so changed values appear side by side. Leases are organized in a building, tenant and document hierarchy, and a portfolio assistant answers plain-language questions such as which leases expire in the next 90 days. Abstracts export to PDF or Word through reusable export profiles, and the app has admin and contributor roles, an audit trail and a review status workflow. Enterprise plans add Microsoft single sign-on and API access, and SharePoint integration is offered as a custom engagement. Abstria is built and run by Al Rafay Consulting, LLC, a Microsoft Solutions Partner based in Bolingbrook, Illinois, and is hosted on Azure. A self-serve free trial is available; paid pricing is not published.

Abstria Features

✦ 200+ Field Abstraction Extracts structured lease data from leases and related documents, typically in a few minutes per document.
✦ Source-Traced Fields Every extracted field links to the exact page and clause in the source PDF.
✦ Dual-Panel Editor Review and correct the abstract next to an inline PDF viewer with document search.
✦ Amendment Delta Tracking Compares an amendment against the original lease and shows old and new values side by side.
✦ Portfolio Hierarchy Buildings, tenants and documents organized in one searchable structure.
✦ Portfolio Q&A Assistant Plain-language questions across all abstracted leases, such as upcoming expirations.
✦ Export Profiles Reusable field subsets for PDF and Word abstract exports.
✦ Roles & Audit Trail Admin and contributor roles, an audit trail and an under-review to reviewed status workflow.
✦ Microsoft SSO & SharePoint Single sign-on and SharePoint Online document sourcing and export on Enterprise plans.
✦ API Access REST API access on Enterprise plans.
