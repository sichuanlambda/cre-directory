About Exquance ModelTree

Exquance ModelTree is a cash flow modeling and valuation platform for real estate and private equity investments from European vendor Exquance Software. Users build automated cash flow forecasts with scenario modeling and value properties using multiple valuation methodologies. It anchors a broader suite that includes Portfolio (web-based portfolio analysis and KPI dashboards), Exquance Insights (submarket data and intelligence), and Fundy (fund management with capital call and distribution tracking). The web-based platform requires no installation and supports data integration plus Excel and automated reporting. Pricing is not published; prospects request a demo.
